A documented Proxmox and Docker environment that includes:

- Home Assistant household dashboards and automation workflows

- Pi-hole, Nginx Proxy Manager, Uptime Kuma, and Homepage
- Plex hardware transcoding through NVIDIA GPU passthrough
- Donetick-backed recurring chore workflows
- Configuration-focused backup and recovery planning
- A least-privilege AI coordination project for Home Assistant

The repository focuses on architecture decisions, troubleshooting, validation, sanitized configuration examples, and known limitations rather than presenting a generic installation guide.
